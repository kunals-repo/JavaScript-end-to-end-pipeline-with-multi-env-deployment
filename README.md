# 🚀 React CI/CD Pipeline on Azure using GitHub Actions & Terraform

## 📖 Project Overview

This project demonstrates a complete **Cloud DevOps CI/CD pipeline** for deploying a **React.js application** to **Microsoft Azure** using:

* ⚛️ React.js
  
* ⚙️ GitHub Actions
  
* 🏗️ Terraform (Infrastructure as Code)
  
* ☁️ Azure Storage Static Website
  
* 🔐 DevSecOps Security Scanning



---

## 🔄 CI/CD Workflow

```text
Developer
    ↓
Git Push
    ↓
GitHub Actions
    ↓
Install Dependencies
    ↓
Unit Testing
    ↓
Security Scanning
    ↓
React Build
    ↓
Artifact Upload
    ↓
Terraform Infrastructure Deployment
    ↓
Deploy to DEV
    ↓
Deploy to TEST
    ↓
Manual Approval
    ↓
Deploy to PROD

```

✅ Multi-Environment Deployment
